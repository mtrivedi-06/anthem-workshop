# Git & GitHub Practice Workshop

## Project Overview
This project demonstrates practical Git and GitHub operations completed as part of the Cloud Computing practice workshop. It focuses on version control, team collaboration, branching, merging, conflict resolution, and recovery.

|---|---|---|

| Sahana | Tester | Anthem file updates and bilingual title feature |

## Technologies Used
- Git
- GitHub
- Linux (Amazon Linux 2023)
- Python
- Flask
- HTML

## Workshop Activities
1. Git configuration and user management
2. Repository creation and cloning
3. Push and pull operations
4. Branch creation, merging and deletion
5. Merge conflict creation and resolution
6. Undo and recovery using Git Reset and Reflog
